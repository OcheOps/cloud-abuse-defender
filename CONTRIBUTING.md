# Contributing

Thanks for helping protect cloud operators from unauthorized resource usage.

1. Open an issue describing the problem, expected behavior and deployment environment.
2. Keep pull requests focused and include tests.
3. Run `go test ./...` and `go vet ./...`.
4. Never include secrets, customer logs, real access keys or identifiable incident artifacts.
5. For containment features, include safety boundaries, least-privilege requirements, failure behavior and rollback procedures.

By contributing, you agree your contributions are licensed under Apache 2.0.
